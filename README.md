# Система семантического поиска по базе знаний компании (MVP)

Проект представляет собой ресурс интеллектуального поиска информации в корпоративных документах. В отличие от классического поиска по ключевым словам, система использует алгоритмы <a href="https://ru.wikipedia.org/wiki/%D0%9D%D0%B5%D0%B9%D1%80%D0%BE%D0%BB%D0%B8%D0%BD%D0%B3%D0%B2%D0%B8%D1%81%D1%82%D0%B8%D1%87%D0%B5%D1%81%D0%BA%D0%BE%D0%B5_%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%B8%D1%80%D0%BE%D0%B2%D0%B0%D0%BD%D0%B8%D0%B5">NLP</a> (обработки естественного языка) и векторные представления (эмбеддинги) для поиска документов по смысловой близости к запросу пользователя.

## 🛠 Стек технологий

* **Язык:** Python 3.10+
* **ML/NLP:** `sentence-transformers` (PyTorch)
* **База данных:** PostgreSQL
* **Среда разработки:** VS Code
* **Сборка:** Docker

---

## Этапы разработки

Проект разбит на 6 основных этапов:

- [ ] **Этап 1. Подготовка окружения и базовой архитектуры**
  - Инициализация проекта, настройка виртуального окружения.
  - Установка базовых зависимостей и запуск "пустого" сервера.
- [ ] **Этап 2. Интеграция NLP-ядра**
  - Подключение `sentence-transformers`.
  - Разработка модуля векторизации текста.
  - Реализация математики для вычисления косинусного сходства (cosine similarity).
- [ ] **Этап 3. Проектирование и настройка базы данных**
  - Подключение БД и создание схемы данных.
  - Реализация базовых CRUD-операций.
- [ ] **Этап 4. Разработка API загрузки документов**
  - Создание эндпоинта POST `/add-document`.
  - Настройка логики: прием текста -> векторизация -> сохранение в БД.
- [ ] **Этап 5. Разработка API поиска**
  - Создание эндпоинта GET `/search`.
  - Настройка логики: прием запроса -> векторизация запроса -> поиск ближайших векторов в БД -> возврат топ-3 результатов.
- [ ] **Этап 6. Тестирование и отладка**
  - Проверка работы API.
  - Тестирование поиска на "хитрых" запросах (синонимы, опечатки, косвенные смыслы).
